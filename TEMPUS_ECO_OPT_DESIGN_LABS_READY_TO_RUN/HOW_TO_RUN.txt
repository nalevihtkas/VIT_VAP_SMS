HOW TO RUN
==========

A. Verify commands:
   tempus -files 00_CHECK_TEMPUS_ECO.tcl

B. Setup ECO:
   cd LAB01_SETUP_ECO
   tempus -files 01_pre_eco_setup_fail.tcl
   tempus -files 02_run_tempus_setup_eco.tcl

C. Hold ECO:
   cd ../LAB01_HOLD_ECO
   tempus -files 01_pre_eco_hold_fail.tcl
   tempus -files 02_run_tempus_hold_eco.tcl

D. Other labs:
   cd each LABxx folder
   ./run_all.sh

WHAT TO LOOK FOR
================
Setup ECO:
  required time should remain essentially unchanged.
  data arrival/max path should improve.
  slack should improve from negative toward zero/positive.

Hold ECO:
  min-delay requirement remains unchanged.
  earliest arrival should move later.
  slack should improve from negative toward zero/positive.

If eco_opt_design -setup or -hold is rejected:
  copy the help text printed by the script and send it back.
  That gives the exact option syntax for your installed build.
