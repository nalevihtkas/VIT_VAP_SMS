LAB OBSERVATION GUIDE
=====================

LAB01 SETUP/HOLD
- Setup FAIL: the 8-buffer max path is too slow for the 4 ns clock.
- Setup FIX: use a relaxed 5 ns clock only as an educational "more valid time"
  demonstration. A real fixed-frequency implementation would optimize the netlist.
- Hold FAIL/FIX: set_min_delay is used to force a visible min-delay exercise.
  In silicon, a real hold fix is normally delay-cell/buffer insertion or CTS/route
  optimization, then Tempus is rerun.

LAB02 CLOCK SKEW / UNCERTAINTY
- Demonstrates how reduced timing margin changes setup/hold.
- For post-CTS silicon-accurate skew, use Innovus extracted clock-tree delays and
  Tempus propagated clocks.

LAB03 MCP
- 01: one-cycle path fails.
- 02: 2-cycle setup constraint gives more setup time.
- 03: adds the companion 1-cycle hold MCP.
- 04: demonstrates that even a 2-cycle MCP can still fail.
- 05: 3-cycle correction is legal ONLY if architecture genuinely allows 3 cycles.

LAB04 HALF-CYCLE
- Launch FF is falling-edge triggered.
- Capture FF is rising-edge triggered.
- Tempus should use opposite edges from the waveform.
- Compare available time against a full-cycle path.

LAB05 FALSE PATH
- The long CFG path is assumed non-timed in NORMAL mode for this exercise.
- First see the violation.
- Then apply set_false_path.
- The correct interpretation is "excluded", not "slack becomes positive."

LAB06 CLOCK GATING
- ICG_X1 contains educational clock_gating_setup_rising and
  clock_gating_hold_rising Liberty checks.
- EN input delay is changed to demonstrate early/late arrival.
- If your Tempus release does not automatically report the gating check with the
  generic report_timing command, use your site's clock-gating/check reporting
  command while keeping the supplied .lib and constraints.
